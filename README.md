# HM Candler

Адаптивный сайт-визитка (лендинг) для магазина свечей ручной работы.

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **SCSS (Sass)** — стилизация, переменные, миксины
- **JavaScript (ES6+)** — интерактивность
- **Vite** — сборка проекта и dev-сервер
- **Swiper.js** — слайдеры и карусели
- **Imagemin** — оптимизация изображений

## ✨ Возможности

- Адаптивная верстка
- Слайдеры товаров на Swiper
- Оптимизированные изображения
- Быстрая сборка через Vite
- Автокомпиляция SCSS в CSS
